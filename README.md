# 멀티 메모 (macOS)

한 화면에 여러 개의 스티커 메모를 동시에 띄우는 프로그램입니다.
메모 개수에 맞춰 화면이 자동으로 나뉘고, 각 메모는 따로따로 `.txt` 파일로 저장됩니다.

## 설치 (처음 한 번)

1. [Releases](../../releases/latest)에서 **MultiMemo_Mac.zip**을 받아 더블클릭으로 압축 해제
2. [python.org](https://www.python.org/downloads/macos/)에서 **macOS 64-bit universal2 installer**로 파이썬 설치
   (맥 기본 파이썬은 화면 기능(Tk 8.6)이 없어서 python.org 버전이 필요합니다)
3. `앱 만들기.command` 더블클릭
   - "확인되지 않은 개발자" 경고가 뜨면: 우클릭(control+클릭) → **열기** → **열기**
4. 1~2분 뒤 **응용 프로그램** 폴더에 `멀티 메모` 앱이 설치되고 실행됩니다.

## 사용

| 기능 | 방법 |
|---|---|
| 새 메모 | ⌘N 또는 ＋ 버튼 |
| 색 바꾸기 | ● 버튼 |
| 삭제 | ✕ 버튼 (`_삭제됨` 폴더로 이동) |
| 글자 크기 5~20pt | 툴바 －/＋ 또는 ⌘ + 마우스 휠 |
| 굵기 | 툴바 얇게 / 보통 / 굵게 |

메모는 `문서/멀티메모` 폴더에 메모별 `.txt` 파일로 자동 저장됩니다.
